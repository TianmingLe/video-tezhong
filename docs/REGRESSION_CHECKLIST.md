# 手工回归测试清单

## 使用说明
每次发版前（nightly / beta / stable），必须按以下清单逐项验证。全部通过后方可发布。

## 1. Onboarding（首次引导）
- [ ] 首次启动应用时，自动进入Onboarding页面
- [ ] Python检测成功路径：检测到Python后显示成功，可继续
- [ ] Python检测失败路径：未检测到Python时显示失败提示和建议
- [ ] 跳过引导：点击跳过后，进入主界面
- [ ] 完成引导后，不再自动进入Onboarding
- [ ] 在设置页点击"重新开始引导"，可以重新进入Onboarding

## 2. Tasks（任务管理）
- [ ] 创建新任务：填写表单后提交，任务出现在列表中
- [ ] 任务执行：点击运行后，状态变为"运行中"
- [ ] 任务取消：运行中的任务可以取消
- [ ] 任务完成：任务正常结束后，状态更新为"已完成"
- [ ] 任务失败：任务异常退出后，状态更新为"失败"
- [ ] 任务历史：已完成的任务在历史列表中可见
- [ ] 队列执行：多个任务按队列顺序执行

## 3. Reports（报告查看）
- [ ] 报告列表：已完成任务在报告列表中可见
- [ ] 日志查看：点击报告可以查看运行日志
- [ ] 日志导出：可以导出日志为文件
- [ ] 归档日志：旧日志可以按chunk读取
- [ ] 缺失归档fallback：归档不存在时，使用内存日志fallback

## 4. Settings（设置）
- [ ] 检查更新：点击后显示更新状态
- [ ] 日志清理：扫描→预览→确认→清理流程正常
- [ ] 反馈问题：生成诊断信息并复制到剪贴板
- [ ] Windows卸载：确认后启动卸载程序并退出（仅Windows）
- [ ] LLM配置：可以保存和清除API Key
- [ ] 托盘配置：左键点击行为切换即时生效
- [ ] 模板配置：可以设为默认、保存为模板

## 5. ErrorBoundary（错误边界）
- [ ] 渲染异常时显示统一错误页
- [ ] 错误页可以复制错误信息
- [ ] 可以返回任务页或重载应用

## 6. Tray（系统托盘）
- [ ] 应用启动后托盘图标可见
- [ ] 托盘菜单可以显示/隐藏窗口
- [ ] 关闭窗口后应用不退出（最小化到托盘）
- [ ] 托盘通知：任务完成时显示通知

## 7. About/Version（版本信息）
- [ ] 关于页面显示正确的版本号
- [ ] Commit hash正确显示
- [ ] Nightly版本有明确标记

## 8. 跨平台验证
- [ ] Windows: 安装包正常安装和运行
- [ ] macOS: DMG正常安装和运行
- [ ] Linux: AppImage正常运行
